## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/nodejs-learning.git
```

### 2. Navigate to the Project

```bash
cd nodejs-learning
```

### 3. Install Dependencies

For any project folder:

```bash
cd project-folder
npm install
```

### 4. Run the Application

```bash
npm start
```

or

```bash
node index.js
```

or

```bash
npm run dev
```

*(depending on the project)*
